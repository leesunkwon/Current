# Current

Kotlin, Jetpack Compose, Android System WebView로 만드는 Android 웹 브라우저입니다.

## 프로젝트 구성

| 위치 | 역할 |
| --- | --- |
| `Current/app` | Compose 화면, 탭·데이터 관리, Android 시스템 연동 |
| `Current/core/browser-engine` | 브라우저 세션과 콜백 인터페이스 |
| `Current/core/engine-webview` | System WebView 엔진 구현 |

`minSdk`는 29, `targetSdk`는 36입니다. 방문 기록·북마크·일반 탭은 Room에, 사용자 설정은 DataStore에 저장합니다. 시크릿 탭은 별도 WebView 프로필을 사용합니다.

## 작업 상태

최종 정리: 2026-09-27. 아래 `[x]`는 **코드에 기능이 연결됨**을 뜻합니다. 기기에서의 동작이나 빌드 성공을 뜻하지 않습니다. 프로젝트 지침에 따라 Codex는 빌드와 테스트를 실행하지 않고 코드·리소스·매니페스트를 점검합니다. 2026-09-27에 전달된 빌드 로그의 `WEB_SEARCH` 컴파일 오류는 `Intent.ACTION_WEB_SEARCH`로 수정했으며, 수정 후 빌드는 실행하지 않았습니다.

## 이번 작업 체크리스트

- [x] **P1 · 현재 웹페이지의 홈 화면 바로가기:** 현재 URL·제목·파비콘으로 고정 바로가기를 요청하고, 런처 확인 및 성공 콜백을 연결했습니다. 시크릿 탭은 제외합니다. PWA 조건을 만족하는 사이트의 바로가기는 독립 화면으로 열립니다.
- [x] **P1 · 추적기 차단 확장:** 내장 제3자 도메인 규칙을 정리·확장하고, 지원 WebView의 일반 프로필 Service Worker 요청과 현재 페이지 차단 건수를 연결했습니다. 출처를 특정할 수 없는 Worker 요청은 차단하지 않습니다. 사이트별 예외는 기존 설정을 사용합니다.
- [x] **P2 · 읽기 기능:** 현재 페이지의 본문을 메모리에서 추출하는 읽기 화면과 사용자 조작으로 시작하는 음성 읽기를 추가했습니다. 시크릿 탭의 음성 읽기는 막습니다. 번역은 지원 방식과 개인정보 경계를 결정한 뒤 별도 작업으로 진행합니다.
- [x] **P2 · PWA 독립 실행:** 같은 출처의 HTTPS 매니페스트에서 독립 표시 방식과 시작 URL·범위를 확인한 사이트를 주소창 없는 별도 화면으로 엽니다. 범위 밖 링크는 일반 브라우저 탭으로 보냅니다.

## 다음 작업 목록

- [x] **PWA 화면 기능 연결:** 일반 탭의 WebView 엔진을 사용하고 문서·카메라 업로드, 권한 확인, HTTP(S)·`blob:` 다운로드와 PDF 열기, 사용자 제스처 팝업, 외부 앱 링크, HTTP 경고 경로를 연결했습니다. 요청 취소·렌더러 종료 시 세션과 임시 파일을 정리합니다.
- [x] **최근 기능 오류 경로:** 이미 고정된 바로가기는 제목·아이콘을 갱신하고, 매니페스트는 같은 출처의 제한된 리디렉션만 따라갑니다. PWA 렌더러 종료와 음성 읽기의 화면 이탈 경로를 정리했습니다.
- [x] **추적기 차단 건수:** 일반 탭과 PWA 화면은 같은 기본 프로필 Worker 라우터를 사용합니다. 다중 프로필 지원 기기에서는 기본 프로필 컨트롤러에만 연결합니다. Worker에 탭 ID가 없으므로 출처가 확인된 요청만 사이트 공유 건수로 표시하며, 다중 탭 중 하나라도 차단 예외이면 Worker 요청을 차단하지 않습니다.
- [x] **읽기 화면:** 제목·문단·소제목을 구분하고 긴 본문을 지연 목록으로 표시합니다. 음성 언어 선택, 일시정지·재개 및 화면 이탈 시 정리를 연결했습니다.
- [x] **기기 내 번역:** 사용자가 읽기 화면에서 번역을 시작하면 [Google Translate](https://translate.google.com)의 ML Kit 언어 모델을 Wi-Fi에서 다운로드하고 기기에서 본문을 번역합니다. 외부 번역 웹 서비스와 API 키는 사용하지 않으며 본문을 저장하지 않습니다. 번역 결과에는 Google 번역 출처와 면책 문구를 표시합니다.
- [ ] 실제 기기의 런처·WebView별 호환성 확인

## Compose 미리보기

Android Studio에서 `Current/app/src/main/java/com/kotlinsun/current/browser/BrowserPreviews.kt`를 열고 **Split** 또는 **Design** 보기를 선택하면 미리보기를 볼 수 있습니다. 미리보기는 WebView와 저장소를 생성하지 않으므로 실제 웹페이지와 네트워크 탐색은 기기에서 확인해야 합니다.

## 제약과 작업 규칙

- 주소창의 **열린 탭·방문 기록 제안은 사용자 요청으로 제거했습니다.** 이를 다음 작업으로 다시 추가하지 않습니다.
- 타사 사이트의 패스키 지원에는 앱 코드 외에 자격 증명 제공자의 승인이 필요합니다.
- 시크릿 다운로드 파일은 기기의 Downloads 폴더에 남습니다. `blob:` 다운로드에는 현재 크기 제한이 있습니다.
- Service Worker 요청에서 출처 헤더를 확인할 수 없으면 차단하거나 탭별 건수로 귀속하지 않습니다. 시크릿 프로필의 Worker 제어는 기본 프로필과 분리되어 있어 이 공유 건수에 포함하지 않습니다.
- 번역 언어 모델은 기기에 저장되며 초기 다운로드에는 Wi-Fi가 필요합니다. 기기 내 번역 품질은 언어와 웹 문서 구성에 따라 다릅니다.
- 실제 API 키가 필요해지면 Android의 `local.properties`에 두고 Git에는 `local.properties.example`만 추가합니다.
- 작업을 시작할 때 이 목록을 확인하고, 완료한 항목은 같은 변경에서 `[x]`로 바꿉니다. 새로 발견한 작업과 제한도 여기에 기록합니다.
- 작업 후에는 변경된 README와 코드를 함께 **한글 커밋 메시지**로 커밋합니다. 코드 변경이 없는 점검·답변에서는 커밋을 만들지 않습니다.
